隱私權政策 / Privacy Policy

最後更新日期 / Last Updated: 2026年3月25日 / March 25, 2026

簡單來說 / TL;DR: 我們不會收集、不會上傳、無法存取您的個人資料。貼圖與設定僅保存在您自己的裝置上。

We do not collect, do not upload, and cannot access your personal data. Stickers and settings stay on your device only.

1. 資料收集與使用 / Data Collection and Use

General Sticker System（以下稱「本擴充功能」）僅在您本地裝置上儲存以下資料：

This extension stores the following data on your local device only:

  • 您添加的貼圖 ID 清單 / Your sticker ID list
  • 貼圖的標籤與分類 / Tags and categories
  • 常用貼圖 / Favorites
  • 自訂標籤詞彙 / Custom tag vocabulary
  • 自定義平台設定（網域、聊天室容器選擇器、掛載／輸入／發送邏輯）/ Custom platform settings (domain, chat container selectors, mount/input/send logic)
  • TSC（實況編織）相關設定與開台狀態快取（約 5 分鐘）/ TSC settings and short-lived stream status cache (~5 minutes)

上述資料使用瀏覽器擴充功能的本機儲存保存，不會上傳至開發者或任何伺服器。

Data is kept in the browser extension’s on-device storage and is not uploaded to the developer or any server.

2. 資料不上傳 / No Data Upload

我們不會 / We do NOT:

  • 將您的資料上傳到任何外部伺服器 / Upload your data to external servers
  • 將資料出售或提供給廣告商 / Sell or share data with advertisers
  • 建立可識別個人的瀏覽紀錄檔案 / Build identifiable browsing profiles
  • 在遠端分析您的聊天內容 / Remotely analyze your chat content

3. 開發者無法存取 / Developer Cannot Access

資料僅在您的裝置上，開發者無法讀取您的貼圖清單、標籤或自定義平台設定。

Because data stays on your device, the developer cannot read your sticker lists, tags, or custom platform settings.

4. 第三方服務 / Third-Party Services

本擴充功能可能與以下服務互動（僅限您使用相關功能時）：

The extension may interact with these services only when you use related features:

  • 直播平台聊天：您手動發送的貼圖 ID 或訊息會出現在該平台聊天室 / Live chat: sticker IDs or messages you send manually appear in that site’s chat
  • 圖片／影片託管（如 Imgur、meee、Catbox 等）：顯示您或他人訊息中的貼圖連結 / Image hosts: to display sticker URLs in chat
  • Twitch、Kick、Vaughn 等 API：TSC 開台狀態查詢（僅公開頻道是否在線等，不需您的登入密碼）/ Stream status APIs for TSC (public online/offline info; no login credentials)

我們不會把您的貼圖庫、標籤或自定義平台設定傳給上述服務。TSC 僅使用您自行輸入的公開頻道網址。

We do not send your sticker library, tags, or custom platform settings to those services. TSC uses only public channel URLs you enter.

5. 權限使用說明 / Permissions Usage

本擴充功能所請求的權限，僅用於下列功能：

Permissions are used only for the purposes below:

本機儲存 / Local storage

  • 保存貼圖、標籤、常用與自定義平台設定 / Save stickers, tags, favorites, and custom platform settings

內建直播平台（安裝時）/ Built-in sites at install

  • 在已列出的直播平台（如 Twitch、Kick、YouTube、Vaughn、w.tv、beamstream 等）的聊天室中，顯示貼圖、將貼圖 ID 轉為圖片、協助發送訊息 / On listed live-streaming sites, show stickers, convert sticker IDs to images, and help send messages in chat
  • 安裝時不會對未列出的網站啟用上述功能（除非您另行新增自定義平台）/ Other sites are not enabled at install unless you add a custom platform

自定義平台（使用者主動）/ Custom platforms (user-initiated)

  • 僅當您在設定中手動新增平台、填寫網域並按儲存時，才會針對該網域請求額外存取權（若瀏覽器支援選用網站權限）/ Extra site access is requested only when you manually add a platform, enter a domain, and click Save (where the browser supports optional site permissions)
  • 您可在瀏覽器提示中拒絕；拒絕則該站不會啟用 GSS / You may deny the prompt; the site will not be enabled
  • 同意後，擴充功能才在該網域啟用與內建平台相同的貼圖腳本（部分瀏覽器透過動態註冊內容腳本實作）/ After approval, the same sticker features are enabled on that domain (some browsers use dynamic content script registration)
  • 不會對您未設定、未同意的網站啟用功能 / Sites you have not configured and approved are not enabled

聊天室 iframe（all_frames）/ Chat iframes

  • 部分平台（如 YouTube）聊天室在 iframe 內；本擴充可能將面板注入該 iframe，僅用於貼圖功能，不收集 iframe 內個人資料 / Some sites use chat iframes; the extension may inject the sticker UI there for sticker features only, without collecting personal data from the iframe
重要聲明 / Important:
本擴充功能不會將您的瀏覽紀錄或分頁網址上傳至外部伺服器。聊天相關處理在您瀏覽器本機即時完成。

This extension does not upload your browsing history or tab URLs to external servers. Chat-related processing happens locally in your browser.

6. 聯絡方式 / Contact

如有隱私權問題，請透過您安裝本擴充功能時所使用的瀏覽器擴充功能商店（如 Chrome Web Store、Firefox Add-ons）之開發者聯絡方式與我們聯繫。

For privacy questions, contact us via the developer contact listed on the extension store where you installed GSS (e.g. Chrome Web Store or Firefox Add-ons).
