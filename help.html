General Sticker System (GSS)

通用貼圖系統

📋 快速開始

使用步驟：

  1. 在 Twitch、YouTube、Vaughn Live、beamstream、w.tv 或 KICK 登入並進入頻道頁面
  2. 開啟插件，輸入貼圖 ID 清單
  3. 點擊聊天室旁的 GSS 圖示開啟貼圖面板
  4. 點擊貼圖快速發送（例如 Twitch/KICK 全自動，其他平台自動填入）

🌐 自定義平台

📍 功能位置： 主面板 ➔ 設定頁 ➔ 自定義平台設定

✅ 內置原生支援平台，無需重複新增：

GSS 已經在底層內置了 Twitch、YouTube、Kick、VaughnLive、BeamStream、W.tv 的原生貼圖管理功能。
除非這些官方網站的底層結構發生重大改變、導致原生功能失效，否則請勿將上述網域重複加到下方的自定義平台中，以免發生腳本執行衝突。

GSS 支援透過「自定義腳本」來擴充對任何直播網站的支持。即使是目前未列出的平台，您也可以透過簡單的設定來啟用貼圖功能。

設定三個關鍵參數：

  • 發動網域： 決定插件在哪個網站啟動（例如：rumble.com）。
  • 聊天室容器： 決定插件要「掃描哪裡」來找出別人的貼圖 ID（CSS 選擇器）。
  • 平台設定： 使用 @ 指令格式定義按鈕位置與發送行為。

📜 平台設定語法

在「平台設定」大文本框中，使用以下 @ 指令格式（每行一個指令）：

  • @hostname domain.com － 發動網域（可選填，若已在上方的網域欄填寫則可省略）。
  • @chatContainer .selector － 聊天室容器，決定插件要掃描哪裡來找出別人的貼圖 ID（可選填，若已在上方的容器欄填寫則可省略）。
  • @logic － 開始定義腳本邏輯，後續每行一個指令：
    • mount: .selector － 決定貼圖按鈕要插在哪個元素旁邊。
    • input: .selector － 決定貼圖 ID 要自動貼入哪個輸入框。
    • send: .selector － (選填) 指定發送按鈕。若未填寫，則在輸入後按 Enter。

📝 實戰範例 (以 Rumble 為例)：

您可以直接在「平台設定」文本框中貼上以下完整配置：

  • @hostname rumble.com
  • @chatContainer .chat-history
  • @logic
  • mount: .chat-message-form-section
  • input: #chat-message-text-input
  • send: .chat--send

💡 提示：您也可以分開填寫，上方填寫網域和容器，下方只填寫 @logic 及其後續指令。

💡 如何取得 CSS 選擇器？

1. 在目標網站按下 F12 開啟開發者工具。
2. 使用選擇工具 ↖️ 點擊網頁元素。
3. 查看該元素的 class (用 . 開頭) 或 id (用 # 開頭)。

🎨 貼圖格式

🌐 GSS 通用圖片連結

格式：GSS-[圖片連結]

  • 支援格式：.jpg, .jpeg, .png, .gif, .webp, .bmp, .svg, .mp4
  • 支援直接連結或相對連結
  • 範例：GSS-https://example.com/image.jpg
  • 範例：GSS-cdn.discordapp.com/attachments/.../image.png

🔍 連結取得方式：

1. 在網路上看到喜歡的圖片
2. 右鍵複製圖片連結
3. 加上 GSS- 前綴即可使用
※ 支援 Discord、Imgur、或其他任何圖片連結

CatBox 圖片/影片

格式：CB-xxx.ext

支援格式：.gif, .png

範例：CB-z8dta6.gif

🔍 CatBox ID 取得方式：

CatBox 網址範例：https://files.catbox.moe/z8dta6.gif

網址最後一段 z8dta6.gif 就是 ID

Imgur 圖片/影片

格式：IM-xxx.ext

  • 支援格式：.gif, .png, .jpg, .mp4
  • 範例：IM-ha3eTC7.gif、IM-abc1234.mp4

🔍 Imgur ID 取得方式：

Imgur 網址範例：https://i.imgur.com/ha3eTC7.gif 或 https://imgur.com/ha3eTC7

網址最後一段 ha3eTC7 就是 ID
使用時請加上 IM- 前綴和副檔名（如 .gif/.mp4），變成 IM-ha3eTC7.gif
※ 若不知道副檔名，可先嘗試 .gif 或 .mp4

meee.com.tw 圖片/影片

格式：ME-xxx.ext

  • 支援格式：.gif, .png（其他格式待確認）
  • 範例：ME-LXEcxGi.gif、ME-HUi2Bs0.png

🔍 meee ID 取得方式：

meee 網址範例：https://meee.com.tw/LXEcxGi

網址最後一段 LXEcxGi 就是 ID
使用時請加上 ME- 前綴和副檔名（如 .gif/.png），變成 ME-LXEcxGi.gif
※ 若不知道副檔名，可先嘗試 .gif 或 .png

🎬 YouTube 影片

統一格式：YT-xxx（系統自動識別影片類型）

https://www.youtube.com/watch?v=xxxx
https://www.youtube.com/shorts/xxxx

🤖 智能模式：

  • Shorts 短影音（9:16 比例）→ 自動靜音循環播放，可點擊播放
  • 一般影片（16:9 比例）→ 顯示縮略圖，點擊播放
  • 系統自動檢測影片類型
  • 在聊天室輸入會自動顯示縮略圖，點擊開啟內建播放器
  • 範例：YT-tGXZNHNhI0I

🔍 ID 取得方式：

youtube.com/watch?v=xxx → ID 是 xxx → 使用 YT-xxx
youtu.be/xxx → ID 是 xxx → 使用 YT-xxx
youtube.com/shorts/xxx → ID 是 xxx → 使用 YT-xxx

📋 平台支援狀態：

Twitch / KICK：完整支援縮略圖與播放器
Vaughn Live：YT- 會顯示縮略圖，但完整 YouTube 連結不會轉換（避免官方攔截）

🏷️ 標籤功能

每張貼圖可添加最多 4 個標籤，方便分類和搜尋。

格式：CB-xxx #meme #reaction

  • 標籤以 # 開頭
  • 每個標籤最多 16 個字元
  • 不能包含空格或 #

💡 提示：右鍵點擊貼圖（在頻道頁面或插件面板）即可快速添加/移除標籤

⭐ 快捷操作

  • ★ 常用標記：點擊貼圖上的 ★ 按鈕將其標記為常用，常用貼圖會置頂顯示
  • ✕ 刪除：點擊 ✕ 按鈕從清單中移除貼圖
  • 右鍵標籤：在貼圖上點擊右鍵可添加或移除標籤

  • 實時狀態顯示：🟢 在線 / 🔴 離線 / ⚫ 未知

🌐 Custom Platforms

📍 Location: Main Panel ➔ Settings ➔ Custom Platform Settings

✅ Native Platforms Supported (No Setup Required):

GSS has natively integrated sticker management for Twitch, YouTube, Kick, VaughnLive, BeamStream, and W.tv.
Unless these official websites undergo major structural changes that break native support, DO NOT add these domains to the custom platforms below to prevent script execution conflicts.

GSS supports adding support for any live streaming website via "Custom Scripts". Even if a platform is not currently listed, you can enable sticker functionality through simple configuration.

Set three key parameters:

  • Domain: Where the script activates (e.g., rumble.com).
  • Chat Container: Where the extension scans for sticker IDs (CSS selector).
  • Platform Config: Use @ command format to define button placement and sending behavior.

📜 Platform Config Syntax

In the "Platform Config" large text box, use the following @ command format (one command per line):

  • @hostname domain.com － Domain (optional, can be omitted if already filled in the domain field above).
  • @chatContainer .selector － Chat container, where to scan for sticker IDs (optional, can be omitted if already filled in the container field above).
  • @logic － Start defining script logic, followed by one command per line:
    • mount: .selector － Where to insert the sticker button.
    • input: .selector － Where to paste the sticker ID.
    • send: .selector － (Optional) Specify send button. If empty, presses Enter after pasting.

📝 Real Example (Rumble):

You can directly paste the following complete configuration into the "Platform Config" text box:

  • @hostname rumble.com
  • @chatContainer .chat-history
  • @logic
  • mount: .chat-message-form-section
  • input: #chat-message-text-input
  • send: .chat--send

💡 Tip: You can also fill them separately - enter domain and container in the fields above, and only enter @logic and its subsequent commands below.

💡 How to get CSS Selectors?

1. Press F12 on the target site to open DevTools.
2. Use the picker tool ↖️ to click on web elements.
3. Find the element's class (starts with .) or id (starts with #).

🌐 カスタムプラットフォーム

📍 機能の場所： メインパネル ➔ 設定ページ ➔ カスタムプラットフォーム設定

✅ 標準対応プラットフォーム（追加不要）：

GSS は既にシステム標準で Twitch、YouTube、Kick、VaughnLive、BeamStream、W.tv のネイティブスタンプ管理機能を搭載しています。
プラットフォーム側の仕様変更により標準機能が動作しなくなった場合を除き、スクリプトの衝突を防ぐため、上記のドメインを下のカスタムプラットフォームに重複して追加しないでください。

GSSは「カスタムスクリプト」を通じて、あらゆるライブ配信サイトへの対応を拡張できます。現在リストにないプラットフォームでも、簡単な設定でステッカー機能を有効にできます。

3つの主要パラメータを設定：

  • 発動ドメイン： 拡張機能が起動するサイト（例：rumble.com）。
  • チャットコンテナ： ステッカーIDをスキャンする場所（CSSセレクター）。
  • プラットフォーム設定： @ コマンド形式でボタン位置と送信動作を定義。

📜 プラットフォーム設定構文

「プラットフォーム設定」大テキストボックスで、以下の @ コマンド形式を使用します：

  • @hostname domain.com － 発動ドメイン（任意）。
  • @chatContainer .selector － チャットコンテナ（任意）。
  • @logic － スクリプトロジックの定義を開始、その後1行に1つのコマンドを入力：
    • mount: .selector － ステッカーボタンの挿入先。
    • input: .selector － ステッカーIDの貼り付け先。
    • send: .selector － (任意) 送信ボタンの指定。未入力の場合は貼り付け後にEnterキー。

📝 実践例 (Rumbleの場合)：

  • 🌐 ドメイン： rumble.com
  • 🏠 コンテナ： .chat-history
  • 📜 プラットフォーム設定：
    @hostname rumble.com
    @chatContainer .chat-history
    @logic
      mount: .chat-message-form-section
      input: #chat-message-text-input
      send: .chat--send

💡 ヒント：

これらの3つのパラメータを別々に入力することも、完全な @ コマンド設定を一度に貼り付けることもできます。
システムは自動的にすべてのコマンドを認識して解析します。

  • 예시: YT-tGXZNHNhI0I

🏷️ 태그 기능

스티커당 최대 4개 태그를 추가하여 분류 및 검색이 쉬워집니다.

형식: CB-xxx #meme #reaction

  • 태그는 # 으로 시작
  • 태그당 최대 16자까지
  • 태그명에 공백이나 # 사용 불가

💡 팁: 스티커를 우클릭(채널 페이지 또는 패널 내)하여 태그를 빠르게 추가/제거

⭐ 단축키

  • ★ 즐겨찾기: ★ 버튼을 클릭하여 스티커를 즐겨찾기에 추가. 즐겨찾기는 상단에 표시됨
  • ✕ 삭제: ✕ 버튼을 클릭하여 목록에서 스티커 제거
  • 우클릭 태그: 스티커를 우클릭하여 태그 추가/제거

🧶 TexoStreamCore (TSC) 스트리머 관리

TSC는 GSS의 스트리머 관리 플랫폼으로, 라이브 페이지에서 다양한 스트리머의 채널을 빠르게 전환하고 공용 채팅 기능을 사용할 수 있습니다.

📋 설정 형식

관리 패널의 【編織】 탭에서 입력:

>Elfin
!https://www.twitch.tv/elfinl
#https://www.twitch.tv/elfinl
#https://kick.com/elfinl
#https://vaughn.live/elfinl
#https://www.youtube.com/@Elfin-Lee

> 스트리머 이름
# 플랫폼 URL
! 공용 채팅 (Twitch / KICK 지원)

🎯 핵심 기능

  • 다중 스트리머 관리: 여러 스트리머의 방송 상태를 동시에 추적
  • 실시간 상태: 🟢 방송중 / 🔴 오프라인 / ⚫ 알 수 없음
  • 패널 제어: 사이트 로고 오른쪽의 ▼ 화살표를 클릭하여 TSC 패널을 펼치기/접기, 플랫폼 배지를 클릭하여 이동
  • 공용 채팅: 예를 들어 Twitch / KICK 채팅을 Vaughn 페이지에 임베드, GSS 스티커 완전 지원 (참고: Twitch 채팅은 보안 정책으로 인해 KICK 페이지에 임베드할 수 없습니다；KICK 채팅은 CSRF 보호로 인해 타사 페이지에서는 조회만 가능하고 발언할 수 없습니다 (KICK 임베드 API 공개 대기 중)；Vaughn Live는 신뢰할 수 있는 감지 방법이 없어 방송 상태가 일시적으로 ⚫ 알 수 없음으로 표시됩니다)
  • 자동 감지: 라이브 페이지에 #GSS-TexoStreamCore 태그를 배치하면 확장 프로그램이 자동으로 아래 데이터를 읽습니다
